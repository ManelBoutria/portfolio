# Portfolio

**Student name:** Manal Boutria
**Module:** WAMD, ENSTA (TD-TP 1)

## Project description

A responsive personal portfolio website that presents who I am, my skills, my projects, my education and my contact information. It adapts to desktop, tablet and smartphone screens.

**Live website:** https://manelboutria.github.io/portfolio/

## Technologies used

- HTML5 (semantic elements)
- CSS3 (Flexbox, Grid, media queries, CSS variables)
- JavaScript (DOM manipulation, events)
- Visual Studio Code
- Git and GitHub Pages
- Browser DevTools (testing and responsiveness)

## Implemented features

- Sections: Home, About, Skills, Projects, Contact
- Semantic structure with header, nav, main, section, article and footer
- Responsive layout for desktop, tablet and smartphone
- Mobile hamburger menu that opens and closes with JavaScript
- Smooth scrolling between sections
- Sticky navigation bar
- Contact links: email (mailto), phone (tel) and GitHub
- Hover effects on buttons and project cards
- Deployed with GitHub Pages
